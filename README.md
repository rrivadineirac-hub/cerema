# CEREMA

Sistema de gestión para CEREMA (Centro de Rehabilitación del Músico y del Artista).

## Descripción
Aplicación web desarrollada en PHP para el registro y administración de socios, aportes, mensualidades, servicios, inventario de activos y reportes financieros.

## Requisitos
- PHP 7.4+ / 8.x
- MySQL / MariaDB
- Servidor Web (XAMPP / Apache)

## Configuración Local
1. Importar la base de datos `cerema_db.sql`.
2. Configurar los accesos en `Config/database.php`.
3. Ejecutar el proyecto en el servidor local.
